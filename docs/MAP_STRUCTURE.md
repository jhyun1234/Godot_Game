# 맵 구조 — 전체 그림

작성: 2026-09-07 (기획 점검 21~22차). **2026-09-09 규칙 개정 3(#25)으로 §0·§2·§7 갱신 — 층 수 3~7 = 난이도, 층 245m, 미로, 광차 순환선.** 근거는 `docs/DESIGN_REVIEW.md` §30.

## 0. 전제 (사용자 결정)
- **밖은 없다.** 게임 내내 광산 안이다. "지상" 이라 부르던 곳은 **광산의 맨 위 층(갱구 대기장)** 이다. 실내, 어둡다, 헤드램프 계속.
- **수거함은 갱도 안에 무작위로 있다.** 맨 위에는 없다. 0원짜리는 다시 아래로 끌고 내려가야 한다.
- 갱도는 **실제 갱도의 구조**를 참고해 짠다.
- 층 하나의 넓이는 **매우 넓게 — Lethal Company 맵 하나 크기** 를 목표로 한다.

```
┌─ 맨 위 층 — 갱구 대기장 (실내·어둠) ──────────────────────────────────┐
│  [게시판: 계약·사진]   [검수대: 구마다 가격·0원]   [광차 대기장]   [수갱 상부] │
└──────────────────────────────────────────────────────────────────┬───┘
                                                           수갱 (10m/층)  ║
┌─ 1층 ─────────────────────────────────────────────────────────────╫───┐
│  주갱도(레일) ━━━ 횡갱 ━━━ 채탄구역(방·기둥) ━━━ 막장                    ║   │
│       ┃              ┃            ┃                                 ║   │
│    승갱·사갱      갱목 구간      [수거함?]  펌프장(물)  통기갱도(가스)  대피소  ║   │
└───────────────────────────────────────────────────────────────────╫───┘
   … 층 수 = 난이도: 3 / 4 / 5 / 6 / 7 (검수대 층은 안 센다. 7층이 최고)
┌─ N층 (맨 아래) ────────────────────────────────────────────────────╨───┐
│  … 같은 문법, 밀도 최대. 끊긴 철길 너머(리프트 안 닿음)                        │
└──────────────────────────────────────────────────────────────────────┘

시신 흐름:  막장·채탄구역 → 끌기 → 광차 → 리프트 홀 → 수갱 → 검수대 → (0원이면) 다시 내려가 갱도 안 수거함
```

## 1. 실제 갱도의 문법 → 우리 조각

실제 지하 광산은 **수갱(shaft)** 으로 내려가 **층(level)** 마다 **주갱도(drift)** 가 뻗고, 거기서 **횡갱(crosscut)** 이 광맥 쪽으로 갈라져 **막장(face)** 에 닿는다.
석탄은 **방·기둥(room and pillar)** 으로 캔다 — 격자로 방을 파고 기둥을 남긴다. 위아래 층은 **승갱(raise)·사갱(incline)** 으로 잇고, 캔 것은 **광석 슈트(ore pass)** 로 떨어뜨린다.
갱도는 **갱목(timber set)** 이 받치고, **통기 갱도**가 공기를, **펌프장(sump)** 이 물을 뺀다. 사고 대비로 **대피소(refuge)** 가 있다.

| 실제 요소 | 우리 조각 (손으로 만든 타일) | 게임에서 하는 일 | 슬롯 |
|---|---|---|---|
| 수갱 + 리프트 홀 | 샤프트 + 층마다 홀 | 층 이동. 광차 종점 | 없음 (안전지대 아님) |
| 주갱도 | 직선·굽은 레일 복도 (7m 격자, 길이 1~4칸) | 광차 길. 광차 소음 | 낙서 |
| 횡갱 | 갈림길 T·십자 | 길 선택. 한쪽은 막힘(벽에 박힌 레일) | 낙서 |
| 방·기둥 채탄구역 | 기둥이 선 넓은 방 (3x3 ~ 5x5 격자) | 시야가 끊긴다 — 괴물이 숨는다. 광맥 포켓이 많다 | 광맥 포켓·시신·동물 |
| 막장 | 막다른 끝. **끝막이 조각**(`mine_face.gltf`, 천공 자국·발밑 홈) — 못 캔다 (#24) | 시신이 가장 많다 | 시신·낙서 |
| 갱목 구간 | 지지목이 촘촘한 복도 | 정비 과제(삐걱). 실패하면 붕괴 게이지 | 지지목 |
| 승갱·사갱 | 계단·경사 (KayKit stairs) | 층 안에서 높이 차. 광차 못 감 — 끌어야 함 | 시신 |
| 광석 슈트 | 수직 구멍 | 광석 던져 내리기(나중). 소리가 아래로 | — |
| 통기 갱도 | 좁은 통로 + 환기구 | 가스 과제(나중) | 정비 |
| 펌프장 | 바닥이 낮고 물이 고임 | 물 과제(나중). 물속 소리 없음 | 정비 |
| 대피소 | 문 달린 작은 방 | 숨는 곳(도망·숨기) | 숨기 |
| **파쇄장** | 실제 광산의 파쇄기 자리 | **수거함(분쇄기)**. 층마다 0~2개, 자리 무작위 | 수거함 |
| 광차 대기장 | 레일이 모이는 넓은 곳 | 맨 위 층·홀 옆. 광차 갈아타기 | — |
| 갱구 대기장 | 맨 위 층 전체 | 검수대·게시판. 실내·어둠 | — |

## 2. 크기 — Lethal Company 맵 하나 = 어느 정도인가

Lethal Company 실내는 손으로 만든 타일(복도·방·계단)을 생성기(DunGen)가 이어 붙인 것이다. 정확한 수치는 공개돼 있지 않다. 겪어 본 감으로 잡으면:
- 실내 한 판: 방·복도 타일 **30~60개**, 끝에서 끝까지 걸어서 **2~3분**, 대략 **100~150m** 폭.
- 우리 TestRoom 은 20m x 20m, 타일로 치면 **하나**다.

| 목표 | 값 |
|---|---|
| 한 층의 발자국 | **245m × 245m** (7m 격자 35 × 35 칸. 규칙 개정 3: 빈 갱도라면 끝 벽까지 걸어서 45~60초) |
| 한 층의 칸 수 | **520~570** (35×35 의 43~46%. #27 실측 시드 7 = 551 · 시드 8 = 528). 조각 = 칸 하나(직선·곡선·갈림)에서 2×2(방) |
| 채탄구역(방기둥) | 층당 3~4개 |
| 방(막다른, 목 하나) | 층당 8~10개(#27 실측. 칸으로는 20~30) — 시신 자리 |
| 광차 순환선 | 레일 130~145칸, 고리 1, 지선 종점 2~4 |
| 정거장에서 가장 먼 곳 | 400~500m (#27 실측 399·476) — 걸어서 90~110초, 광차로 30초 안팎 |
| 층 수 | **3 / 4 / 5 / 6 / 7** = 난이도 |

## 3. 이 크기가 규칙 하나를 바꾼다 — 절차 생성

지금 규칙(CLAUDE.md §15)은 **"절차적 생성은 하지 않는다. 손으로 만든 층을 순서만 섞는다"** 다.
Lethal Company 크기의 층을 **6개, 손으로** 만들면 조각 200~270개를 하나하나 배치하는 일이고, 판마다 다르지도 않다. 이 크기에서는 그 규칙이 못 버틴다.

Lethal Company 가 하는 방식이 답이다: **조각은 손으로, 조립은 시드로.**

| | 손으로 층 6개 | 조각 손 + 조립 시드 |
|---|---|---|
| 만드는 것 | 층 6개 (조각 250개 배치) | 조각 15~20종 + 조립 규칙 |
| 판마다 | 같다 (순서만 섞임) | 다르다 |
| 시간 | 주 단위 | 조각 며칠 + 조립기 며칠 |
| 품질 | 손맛은 좋으나 두 번째 판부터 외운다 | 조립 규칙이 나쁘면 미로가 된다 — 규칙에 품이 든다 |
| 봇 검사 | 층마다 | 시드 고정으로 같은 층을 다시 만들어 검사 |

조립 규칙은 실제 갱도 문법을 따른다: 홀에서 주갱도가 나가고, 주갱도에서 횡갱이 갈라지고, 횡갱 끝에 채탄구역·막장이 온다. 갱목 구간·펌프장·대피소·파쇄장은 사이에 끼운다.
격자(7m, #22 이전 4m)와 문법이 있어서 "아무 데나 붙는" 미로가 아니라 **광산처럼 읽히는** 배치가 된다. 이것이 손으로 만든 모듈 8~12개를 섞는 이전 안(§ 이전 판) 을 대체한다.

**결정 사항:** 규칙을 "조각은 손으로 만들고, 조립은 시드로 한다" 로 바꾼다. 제안서 #16 에 넣는다.

## 4. 수거함이 갱도 안에 있다는 것
- 검수는 맨 위. 0원이 뜨면 그것을 **다시 리프트에 실어 내려가** 파쇄장까지 끌어야 한다. 규칙(§24)을 지키며 광차·레일·갱목 구간을 지난다. 이것이 A 문장의 길이다.
- 파쇄장 자리는 층마다 0~2개, 시드가 정한다. 어느 층에 있는지는 내려가 봐야 안다 — 또는 낙서가 알려준다.
- 그것을 싣고 내려가는 리프트 6초는 가장 긴 6초가 된다.

## 5. 맨 위 층 — 갱구 대기장
- 실내. 어둡다. 램프 하나. 회사의 검수 기계와 게시판만 밝다(그 빛이 유일한 고정 광원).
- 검수대 / 게시판(계약·사진 12장 + 빈 못) / 광차 대기장 / 수갱 상부. **수거함 없음.**
- 안전지대인가 — 아니다. "그것들은 위에 있다"(29줄). 깨어난 것(b-1)이 어디로 가는지는 결말 설계에서.

## 6. 층 3 (거짓 단서) 해금 조건 — 미정
기록(검시 일지)을 두지 않기로 했으므로 "기록에 줄이 있으면" 은 못 쓴다. **층 3 을 기획할 때 다른 방식을 정한다.** 후보만 적어 둔다:
- 난이도 선택만 (매우 어려움 = 거짓 단서 있음. 설명 없음)
- 세션 안 회차 수 (저장 없이)
- 갱도 번호 (7번 갱도 이후는 뒤집혀 있다 — 세계 설정)
- 낙서가 알려준다 ("이 갱도의 시신은 거짓말을 한다" — 세계에 있는 것이라 기록이 아니다)
지금은 표의 조건 열을 비워 둔다.

곡선 = 두 면을 잇는 호(가운데 반지름 3.5m, 복도 폭). 직각 L 은 없다. 레일 곡선도 같다.

**#27 에서 프로토타입과 달라진 것 7.** ① 정거장 1×2(한 열) ② 정거장 앞 직선 레일 3칸(`ENTRY_STRAIGHT`), 그 끝에서 순환선이 갈라진다 ③ 레일 막다른 끝은 항상 끝막이 + 종점 버퍼(방 아님, 가지·고리 안 붙음)
④ 2×2 방은 목 앞 칸이 방의 남서 칸 하나뿐(미러 없음, 안 되면 1×1) ⑤ 대피소는 옆 칸(조각 로컬 E)이 비어 있을 때만 놓고 그 칸을 바위(`rock`)로 예약 ⑥ 펌프장·갱목 구간·천장 구멍은 종류만(조각 없음 → 직선)
⑦ 레일 4방향 교차는 직선 레일 2개 겹침. 순환선이 자기와 만나면 레일 고리가 2가 된다(시드 7) — 검사는 "≥ 1".
칸 (cx, cy) → 월드 x = (cx − 16) × 7, z = (cy − 32) × 7 − 3.5. 입구 (16, 32) = (0, −3.5). 조각 회전 r = rotation.y = r × 90°(로컬 면 f → 세계 (f − r) mod 4).
숨는 곳: 대피소(문)·광차 안·방 구석·기둥 뒤. 튀어나올 곳: 곡선 뒤·기둥 사이·방의 목·천장 구멍.
층이 깊을수록(광산의 아래층) 칸 ↓ 방 크기 ↑ 시신 ↑ — 값은 층 3 이상 만들 때.
